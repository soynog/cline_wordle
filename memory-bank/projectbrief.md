# Project Brief: Command-Line Wordle

## Overview
Create a command-line implementation of the NYTimes Wordle game, providing an engaging word-guessing experience through a text-based interface.

## Core Requirements

### Game Rules
- Players get 6 attempts to guess a 5-letter word
- After each guess, provide feedback using colors/symbols:
  - Correct letter, correct position (green/✓)
  - Correct letter, wrong position (yellow/○)
  - Letter not in word (gray/✗)
- One game per session
- Valid word checking

### MVP Features
1. Command-line interface with clear visual feedback
2. Core game logic implementation
3. Word validation system
4. Basic game state management

### Future Enhancements (Phase 2)
1. Statistics tracking
2. Save/load game progress
3. User preferences
4. Extended word dictionary

## Technical Scope
- Implementation in Python
- Focus on maintainable, modular code
- Clear separation of concerns
- Cross-platform compatibility

## Success Criteria
1. Faithful recreation of core Wordle mechanics
2. Intuitive command-line interface
3. Responsive and reliable gameplay
4. Clear feedback system
5. Error handling for invalid inputs

## Out of Scope (Initial Release)
- Multiplayer functionality
- GUI interface
- Advanced analytics
- Custom game modes
- Word difficulty ratings
